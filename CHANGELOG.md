# Changelog

## Unreleased research demo

- Pinned Android build tools, local build/device instructions and manual-only CI.
- Bounds-checked resource extraction, indexed PICT catalogs, supported PCM sound
  conversion and evidence-linked research tooling; originals stay private.
- Portable CMake engine, stable C ABI errors, versioned saves and atomic host storage.
- Adaptive Android controls and runtime regressions; optional shared SDL desktop host.
- Synthetic mutation tests, ASan/UBSan and Python coverage gate.
- MIT for newly written project code; historical content is separately restricted.

This remains a synthetic prototype. Original game rules, complete reference
traces, faithful Classic presentation, original audio sequencing and native
Windows/macOS acceptance are not represented as complete. No signed public
release has been made by this work.
